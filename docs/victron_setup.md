# Victron / Cerbo Setup

- **Venus OS Large** on Cerbo (Node-RED & MQTT available)
- **Services → MQTT**: On (Local broker)
- **Settings → DVCC**: On (SVS On, Shared sense if used)
- **System Setup → Battery monitor**: select virtual/aggregate battery (not Automatic)
- Optional: install `dbus-aggregate-batteries` or `dbus-mqtt-battery` if not using Node‑RED Virtual Battery.
