# Safety & Commissioning Checklist
- Equalize pack voltages to within 50–100 mV before first parallel.
- Verify polarity and torque; install Class‑T fuses.
- Pre-charge testing per pack; confirm ΔV < 0.3–0.5 V within 0.8–3.0 s.
- MAIN close feedback via aux contact (MAIN_FB_i).
- DVCC on; virtual battery chosen; MQTT on.
- Fault drills: BMS trip, network loss, pre-charge failure.
